__H2Y:__ Intended as the base extension, for more conservative map authors and/or source port authors wanting to port Boom over to Heretic without much hassle.

__H2Y+:__ Intended as a superset of H2Y, similar, but not exactly the same as MBF21. Intended for more experimental source ports, or those more comfortable with MBF21 than limit-removing.

Ideally, the cross-port ACS proposal should also be implemented, but optional for map authors. [More info on that can be found here.](https://gist.github.com/Gutawer/25d5690569f78ea9ff7f41956ef30472)

Although the initial idea is to have ACS support for both H2Y and H2Y+, I'd also be willing to limit ACS support to the latter only if ACS is deemed out-of-scope for a Boom equivalent.
