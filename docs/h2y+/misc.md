## Misc. H2Y+ Specification Stuffs
Cross port ACS should be implemented here, whever the same should apply to H2Y... we'll see.

* HELPx: Allows for more than two helpscreens, up to nine
* CREDITSx: Allows for multiple credit screens, or general static graphic images
* If H2Y only allows for two horizontal/vertical screens at a time, allow up to four here
* Maybe rely on UMAPINFO for episode map flow and/or secret map placement, falling back on H2Y behavior when not found?
* TINTTABx: Allows for different transparency handling for some entities, perhaps defined in HHX+
* HHX&####: General purpose HHX sprite number [&], sprite frame [####].
* LOOPSND&: General purpose looping sound number [&].
* AMBIENT&: General purpose random ambient noise number [&]
